# web

React + TypeScript + Vite implementation of the design system. See the [root README](../README.md) for the whole project.

```bash
npm install
npm run dev      # demo catalog at http://localhost:5173 (one page per foundation and component)
npm run build    # type-check and build
npm run lint     # oxlint
```

Components are in `src/components/`, tokens in `src/styles/` (`primitives.css`, `tokens.css`), English and Japanese strings in `src/i18n/`.
